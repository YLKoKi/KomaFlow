# KomaFlow 使用说明

> 当前版本 **V1.2.0-beta**（测试版：接口与默认值可能调整）。
> 流水线：装配 → 30 帧物理预热 → 分段渲染 → 出 MP4 / 透明 MOV。

本文讲"界面上怎么操作、每个默认行为是什么意思"。
技术细节见 [architecture.md](architecture.md)。

---

## 一、跑起来

| 需要 | 说明 |
|---|---|
| Windows 10 / 11 64 位 | 仅 Windows |
| Blender 5.0 – 5.99 | 不自带，用你已装的；实测 5.2.3 LTS |
| mmd_tools 扩展 | 装在 Blender 里；界面可一键触发安装 |
| FFmpeg | 不随包分发；可在你同意后按固定版本下载（校验 SHA256），也可自备并加入 `PATH`（或用 `KomaFlow_FFMPEG` 指定目录） |

> 缺 FFmpeg 时，程序会在三处问你：首次启动、点「开始渲染」出透明 MOV 时、以及设置里手动点
> 「下载 FFmpeg」。三处走的是同一个下载器（固定版本 + SHA256 校验）。

双击 `KomaFlow.exe`。首次启动会自己找 Blender：

- 只找到一台 → 直接用
- 找到多台 → 让你选，选完记住
- 一台都没有 → 告诉你去哪下

## 二、界面上怎么用

四张卡 = 四个输入：**角色模型 / 动作 / 镜头 / 舞台**。
把文件拖进去，或点卡片选择。

### 各卡收什么

| 卡 | 收 | 说明 |
|---|---|---|
| 角色模型 | `.pmx` / `.pmd` / `.blend` | 放 `.blend` = 用你配好的整份工程 |
| 动作 | `.vmd`（可多个） | 表情 VMD 也放这里，按拖动顺序叠加 |
| 镜头 | `.vmd`（可留空） | 留空则自动生成正面机位 |
| 舞台 | `.pmx` / `.pmd` / `.blend` | 留空则按渲染背景设置处理 |

### 三个按钮

| 按钮 | 作用 |
|---|---|
| **单帧预览** | 渲一帧看构图（会先装配；之后与整片共用同一份工程）|
| **渲染模型** | 把一个 `.pmx` 渲成三视图，同时存一份可编辑 `.blend`；不产生成片 |
| **开始渲染** | 走完整流程出片 |

顶栏另有「组装为工程」：只装配、不出片，方便你拿 `.blend` 去 Blender 里改。

## 三、几个默认行为

| 项 | 默认 | 说明 |
|---|---|---|
| 渲染背景 | **关**（出透明）| 拖入舞台/背景后**自动变开**（照背景渲）|
| 物理 | **恒开** | 界面上没有开关：导入 → `build_rig` → 烘焙，全自动 |
| 观感 | **能力包** | 材质来自「渲染模型」调好的那份工程；不再提供"MMD 原味"选项 |
| 预热 | 30 帧 | 前 30 帧静置让头发裙摆收敛，第 30 帧起动作生效 |
| 分段 | 约 1000 帧/段 | 断点续渲；已完成的段不会重跑 |
| 骨骼匹配 | **<35% 中止** | 动作和模型骨骼对不上就不渲整片；`KOMEFLOW_ALLOW_LOW_MATCH=1` 可强制继续，35%~60% 只警告 |

## 四、装配只做一次

点「开始渲染」或「单帧预览」时，如果还没装配过，程序会先装配：

```
导入素材 → 建物理约束(build_rig) → 烘焙 → 保存工程(.blend)
```

装配完会在**出图目录**留一份 `<成片名>.blend`（含烘焙好的物理）。

之后：

- 改渲染区间、改分辨率、重开程序 → **直接复用这份工程，不重跑物理**
- 你手动打开这份 `.blend` 改了材质/灯光/镜头 → 下次渲染会用你改过的版本
- 换了模型/动作/舞台/预热 → 判定为素材变化，**重新装配**并覆盖工程文件（日志会提示）

## 五、日志与排错

- 总日志：`<工作目录>/logs/KomaFlow.log`
- 装配日志：`<工作目录>/build.log`
- 段渲染日志：`<工作目录>/render_seg0000.log`
- 出错时日志里会有完整调用栈（"出错的调用栈" 那几行）

装配/烘焙阶段界面会依次显示：

```
正在装载（xxx.pmx）… → 正在开启物理… → 正在装载（xxx.vmd）…
→ 正在烘焙物理…（已用 10 秒）→ 正在保存（xxx.blend）… → 正在渲染视频…
```

## 六、常见问题

**Q：找不到 Blender**
先确认装的是 `blender.exe` 本体（不是桌面快捷方式）。程序会扫所有盘符的常见位置、
注册表安装记录、Steam 库、桌面/下载；还找不到就用「自己选路径…」手动指过去。

**Q：mmd_tools 缺失**
界面会提示。可以在设置里触发安装（会由 Blender 去官方扩展库下载）。

**Q：提示"骨骼匹配率太低"、装配直接中止**
角色卡里放的多半是三视图 `.blend`，它的骨骼名和动作对不上（<35%，会白渲整片）。
换成角色原本的 `.pmx`；`.blend` 只能放「舞台」卡。
确实要用就设 `KOMEFLOW_ALLOW_LOW_MATCH=1` 强制渲（35%~60% 只警告，不中止）。

**Q：渲完没有物理（头发裙摆不动）**
- 放的是 `.blend` 且里面本来就没有刚体 → 只能改用 `.pmx`，或重渲一次「渲染模型」
- 日志里会有「物理：build_rig 建了 N 条骨骼跟随约束」「已烘焙 x~y 帧」作为依据

**Q：镜头进了地里 / 机位很低**
多半是镜头 VMD 单位不匹配（导出时没按 1/0.08 换算）。程序会在日志里警告
「镜头机位偏低：相机最低 X 米，角色脚底 Y 米」。

**Q：成品没有透明通道**
检查「渲染背景」是不是"开"；有舞台/背景时透明会被忽略（日志会写明）。

**Q：提示找不到 FFmpeg**
二选一：

1. 让程序下：设置 → 渲染环境 → 「下载 FFmpeg」（固定版本，下完会校验 SHA256）。
2. 自己装：把 `ffmpeg.exe` 放进 `PATH`，或用环境变量 `KomaFlow_FFMPEG` 指定目录；
   程序也会自动找 WinGet / Scoop / Program Files 里的安装。

只想要图片的话，把输出格式改成「PNG 图片序列」——那条路不需要 FFmpeg。

## 七、合规提醒

本工具**不附带**任何模型、动作、舞台、音乐、图片。
请自备合法来源的素材，并遵守原作者的使用规约（常见为"禁止二次配布""禁止商用"）。
本软件**不授予**任何素材使用权。
